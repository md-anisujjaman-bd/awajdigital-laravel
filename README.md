## Installation

You can install the package via Composer:

```bash
composer require md-anisujjaman-bd/awajdigital-laravel
```

You may publish all the package's resources at once with:

```bash
php artisan vendor:publish --tag="awajdigital-laravel"
```

Or, you may publish each resource individually:

### Publishing the Configuration File

```bash
php artisan vendor:publish --tag="awajdigital-laravel-config"
```

### Publishing and Running the Migrations

```bash
php artisan vendor:publish --tag="awajdigital-laravel-migrations"
php artisan migrate
```

### Publishing the Views

```bash
php artisan vendor:publish --tag="awajdigital-laravel-views"
```

### Publishing the Translations

```bash
php artisan vendor:publish --tag="awajdigital-laravel-lang"
```

### Publishing the Public Assets

```bash
php artisan vendor:publish --tag="awajdigital-laravel-assets"
```
